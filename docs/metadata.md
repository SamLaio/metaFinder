# 書目欄位與查找規則

[回到使用說明](../README.md)

## 書目欄位

| 欄位 | 內容與核對重點 |
| --- | --- |
| `title`、`subtitle` | 主標與副標；核對是否為同書、單冊或套書 |
| `authors`、`translators` | 作者與譯者陣列；不將繪者、作者簡介或譯者序混為署名 |
| `publisher`、`published_date` | 出版社與出版日期；網路小說最後更新日不能代替出版日 |
| `isbn`、`eisbn` | 紙本與電子識別碼分開，不能互相複製或改標 |
| `series`、`series_index` | 系列與冊次，需核對版本與集數 |
| `language`、`description` | 語言與保留段落的內容簡介 |
| `tags`、`awards` | 題材、已核實作者地區與可驗證獎項 |
| `cover_url` | 原圖網址；使用前檢查同書同版及畫質 |

採用實際核實的識別碼：找到可靠 ISBN 就保存 ISBN；找到 eISBN 就另存 eISBN。兩者都有時分開保存；只有 ISBN 也可使用，不因書檔為電子書而捨棄紙本 ISBN。13 位條碼僅接受 978／979 開頭，但此篩選不代表已驗證校驗碼或版次。

## 搜尋、解析與候選排序

瀟湘書院的單書頁使用主書名、作者專屬區塊與作品簡介，避免採到推薦書作者；大塊文化商品頁優先讀內容簡介區塊。Readmoo 的簡介在獨立「作者／譯者介紹／簡介」標題前停止，不將人物傳記併入故事摘要。

查找使用站內搜尋及有限度的公開搜尋後備；ISBN 查詢要求識別碼精確命中。書名查詢會嘗試繁簡、常見字形、作者別名與集數變體。明示冊次時排除冊次不同或無法確認的候選，避免小說、漫畫、合輯與套書混配。

來源偏重出版社、主要書店與可核對館藏。解析涵蓋 JSON-LD、網頁 metadata、可見欄位與站台專用區塊；書店搜尋卡有機會再抓商品詳頁。常見來源包括博客來、Readmoo／琅琅、三民、Pubu、Kobo、BOOKWALKER、城邦、讀書共和國、大雁、皇冠、東立與 KADOKAWA，以及晉江、番茄、起點等作品頁。這不是所有頁面均可解析的保證。

分數綜合來源、查詢相關性與完整度。完整書名與作者比對優先於單一泛詞命中；單本商品頁優先於推薦、搜尋列表或通用首頁。作者與冊次衝突時可能排除候選，寧可空結果也不合併不同書。

## 系列、標籤與獎項

尾端集數與 `PART`、`NO.`、`～系列之三` 等格式可提供系列證據，例如 `我獨自升級8` 對應前置冊次 `08`，`木頭猛男追新娘～City Hunter NO.4` 對應系列 `City Hunter`、第 4 冊。明確系列標記的證據強於一般分類詞；年份及副標中的上下篇不能任意當冊次。

標籤採短而精確的詞，例如 `言情`、`小說`。作者地區只採已核實對照或明確證據，不從姓名、出版社所在地或故事舞台推測。作者對照集中在 `src/metafinder/tags.py`，新增對照須有可反查來源。

獎項不從推薦文中的「得獎」字樣自動推論。只有目前來源是可信獎項紀錄，且作品、作者與得獎／入圍語境相符時才輸出獎項及相關標籤；需要進一步人工反查時留空。

## 套入書庫前的檢查

核對同書、作者、譯者、冊次、版次與識別碼，確認簡介沒有混入推薦書、作者傳記、目錄或截斷摘要。已確認正體出版文字應保留原署名與用字。`source_url` 是查證線索，不能自動當作 Calibre 的「來源」自訂欄位。

工具不直接回寫 Calibre；實際採用與同步由呼叫端負責。

封面下載只取得候選提供的圖片，不核驗解析度、同書同版或是否為占位圖，也不會嵌入 EPUB。下載後仍需由呼叫端檢查並決定是否採用。
